# Anchor Suite Seed

This zip is a seed for **Anchor** – a local, immutable ledger and its surrounding ecosystem
(Pod integration, Ember memory adapter, and UI panel).

It is not a finished product; it is a *coherent starting point* for an agentic coder
(Ember + Claude Code) to flesh out, refactor, and extend.

## Contents

- `anchor/` – Python package for the Anchor CLI + HTTP API + onboarding.
- `frontend/` – TypeScript React components for the Anchor panel in the Pod UI.
- `docs/` – Story + system rules + architecture notes for the organism.

You can treat this as:

- a reference implementation,
- a design spec,
- and a narrative spine for the system Ember is helping you build.
