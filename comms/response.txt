Next, you can create a basic Flask application with a single route to handle incoming requests. Here’s a simple example:

```python
from flask import Flask

app = Flask(__name__)

@app.route('/')
def hello_world():
    return 'Hello, World!'

if __name__ == '__main__':
    app.run(debug=True)
```

```
