# Anchor v0.1 Launch Notes

## The Spine Exists
This is the first public release of Anchor — a local, immutable ledger for ideas,
decisions, experiments, and project history.

### Included in v0.1

- Append-only ledger (SQLite + SHA-256 integrity)
- CLI: add, list, verify, export, serve
- Python API: Ledger class
- HTTP API: /entries, /verify, /health
- First-run onboarding
- Examples and static website

Philosophy: Local-first. Append-only. Human-usable. No cloud. No crypto.
