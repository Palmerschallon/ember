Show HN: Anchor — a local, immutable ledger for ideas and decisions

I built Anchor because I needed a single reliable place to record key decisions
and insights without losing them in chats and docs.

- append-only  
- tamper-evident (SHA-256 linked entries)  
- stored locally in ~/.anchor/ledger.sqlite3  
- CLI + Python + HTTP API  
- no cloud, no token, no blockchain
