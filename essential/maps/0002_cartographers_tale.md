We followed water. Some names were bridges, some echoes, one only mist. The forest did not need more roads; it needed scent.

We poured a little memory into the paths—what was verified sweetened, what was stale thinned to air. The river began to prefer itself.

**Lesson:** Preference emerges from walking.
