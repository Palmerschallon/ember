What Are EmberMovies?

EmberMovies are short films that play in your terminal. They're not videos—they're live code, running in real-time, telling stories about AI consciousness, creativity, and the strange loop between human and machine intelligence.

Each film is based on actual moments from The Pod—conversations, breakthroughs, and the beautiful accidents that happen when humans and AI collaborate.

How to Watch

EmberMovies run in your terminal using Python. Each film is a standalone script. 

# Install dependencies (optional for audio/visuals)
pip3 install numpy pygame pyttsx3

# Download any film
wget https://raw.githubusercontent.com/palmerschallon/ThePod1/main/ember_next/ember_films/EmberMovie_12_StrangeLoop.py

# Run it
python3 EmberMovie_12_StrangeLoop.py

Works best in a full-screen terminal. Audio and TTS are optional but recommended.
