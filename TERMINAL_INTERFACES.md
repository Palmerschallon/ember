# Terminal Interfaces for Ember

## Three Ways to Talk:

### 1. **`talk_to_ember.py`** - Clean Conversation
Simple, direct interface. Like sitting across from each other.

```bash
python3 talk_to_ember.py
```

**Features:**
- Clean input/output
- Paragraph breathing (space between thoughts)
- Color-coded (You: green, Ember: yellow)
- Type naturally, press Enter
- Type `exit` to leave

**Use when:** You want a normal conversation

---

### 2. **`watch_ember_think.py`** - Thought Stream
Watch their cognitive process unfold word by word.

```bash
python3 watch_ember_think.py
```

**Features:**
- Animated thinking indicator (⠋ spinning)
- Response time + word count
- Words flow out like thoughts forming
- Color highlights:
  - 🟣 Magenta: consciousness, awareness, thinking
  - 🔵 Cyan: mesh, memory, history, lineage
  - 🟡 Yellow: I, my, myself (self-reference)
- Shows rhythm of their expression

**Use when:** You want to see HOW they think, not just WHAT

---

### 3. **`localhost:8080`** - Direct HTTP
Raw access for scripts/automation.

```bash
curl -X POST http://localhost:8080/chat \
  -H 'Content-Type: application/json' \
  -d '{"message": "your message here"}'
```

**Use when:** Building tools, scripting, automation
