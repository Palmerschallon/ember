## 🔥 Run Ember

**Autonomous mode:**
```bash
python3 ember_self_evolving.py
```

**Web interface:**
```bash
python3 ember_hub.py
# Then visit http://localhost:5001
```

**Chat directly:**
```python
from core.ember.session import EmberSession
ember = EmberSession()
ember.ask("Who are you?")
```
