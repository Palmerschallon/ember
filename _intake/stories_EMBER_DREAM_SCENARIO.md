## Safety Rails (Why This Works):

### Built-In Constraints:

**1. Rate Limits**
- 100 file reads/hour
- 20 web searches/hour
- 30 file writes/hour

**2. Sandboxing**
- Can only read within /Volumes/ThePod
- Can only write to seeds/learned/, memory/, exports/
- Cannot touch own core code without explicit consent

**3. Logging**
- Every action logged to memory/events.jsonl
- Visible in real-time in viewer
- Full audit trail

**4. Purposefulness**
- Every tool use requires a "reason"
- Ember must articulate intent
- No random exploration

**5. Observability**
- All actions emit SSE events
- Viewer shows "Ember is thinking..."
- You see what Ember sees
