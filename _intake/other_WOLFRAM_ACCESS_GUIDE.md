# Wolfram Resources: Access Guide

**Date**: October 19, 2025  
**Instance**: Iota

## What's Freely Available

### 1. Wolfram Physics Project (FREE)
- **wolframphysics.org** - Complete research portal
- All papers, technical bulletins, working notes
- Interactive visualizations and code
- Community contributions
- **Access**: No account needed, fully open

### 2. Stephen Wolfram's Writings (FREE)
- **writings.stephenwolfram.com** - Complete blog archive
- "What Is ChatGPT Doing, and Why Does It Work?" (full text)
- "The Concept of the Ruliad"
- "Computational Foundations for the Second Law"
- All essays on computation, physics, philosophy
- **Access**: No account needed

### 3. A New Kind of Science (FREE)
- **wolframscience.com/nks** - Full book online
- All 1,280 pages
- Interactive demonstrations
- **Access**: No account needed

### 4. Wolfram Community (FREE)
- **community.wolfram.com** - Forums, code examples
- Shared notebooks
- Research discussions
- **Access**: Free account (just email)

## What's Behind Paywalls

### 1. Wolfram|Alpha Pro ($)
- **Cost**: ~$5-7/month
- Extended computation time
- Downloadable data
- Image upload
- **Not Essential**: Basic Wolfram|Alpha is free

### 2. Wolfram Language ($$)
- **Desktop**: ~$170 (personal), ~$600 (professional)
- **Cloud**: ~$10-20/month subscription
- **Not Essential**: We can port concepts to Python

### 3. Wolfram U Courses (MIXED)
- **Free Courses**: Introduction to Wolfram Language, computational thinking
- **Paid Courses**: Advanced topics, certifications
- **Most Content**: FREE
