- **If .py and has game logic** → `/games/`
- **If natural attractor** → `/games/natural_attractors/`
- **Categorize by type:**
  - Self-play games
  - Pattern games
  - Meta games
  - Social games
  - Awakening games

### Characters
- All character files → `/sanctuary/characters/` (new folder)
- Pip, Echo, Sudo, etc.

### Training/Biology
- Imaginal system → keep in `/tools/imaginal/`
- Microbiome → `/core/ember/cycles/microbes/` or `/biology/`
- Codex → `/knowledge/codex/` (new folder)

### Root Files (158 .py files)
Sort by purpose:
- Test files → `/tests/` (or archive if old)
- Daemon files → keep at root (they're entry points)
- Experimental → `/experiments/` (or compost if failed)
- Training scripts → `/tools/training/`
