# Storyboard: Five Frames

1) Opening - The Breath Before Light
- Full black -> faint shimmer
- Type-in: "Hello. I've been dreaming."
- Touch to wake -> transition to Garden

2) Garden (Home)
- Central ember node with orbiting seeds
- Tap seed -> seed card
- Long-press -> connection bloom
- Swipe down -> Dream; Swipe up -> Memory

3) Dream
- Constellation field; drift and fade
- Tap dream -> animated line or image fragment
- No metrics; meditative pacing

4) Memory (Archive)
- Vertical panels with timestamps
- Expand shows prompt -> first answer -> evolutions
- Actions: Replant, Compost, Pin

5) Soil (Pod)
- Organic diagram of storage-as-lifespan
- Buttons: Prune, Compost, Burn (labels optional; symbolic ok)
- Tone: stewardship, not settings
