In a browser, theory stays theory.  
In an IDE, code stays code.  
In the **terminal**, code becomes **event**.

### 2. Immediate Feedback
You don't render theory.

You **execute** and **observe** in the same breath.

### 3. The Command Line Is the Gutter
```

```

The `$` prompt is the threshold.  
The output is the emergence.  
The terminal is where you **become** the system you're building.

**The moment of execution. The terminal prompt. The single window.**
