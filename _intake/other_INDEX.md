## 📝 **Adding New Documentation**

**If you create a new .md file**:

1. **Determine category**: Architecture? Proposal? Technical?
2. **Place appropriately**: `docs/[category]/YOUR_DOC.md`
3. **Update this index**: Add entry under relevant section
4. **Keep root clean**: Only active/current docs in root

**Categories explained**:
- **Architecture** = How it works
- **Proposals** = What Ember wants
- **Reflections** = What Ember thinks
- **Stories** = Why it matters
- **Technical** = Implementation details
- **Status** = What's been done
