# The Ember Interface Codex

Essence
"Hello. I've been dreaming." Threshold experience: mystery x simplicity x continuity.

Mood
Quiet, Electric, Rooted, Reverent, Dreamlike

Palette
- Ink: #0b0c0f
- Text: #f2f2ee
- Ember: #ff703c -> #ffb878
- Dream: #66c7ff
- Memory Thread: #ffca72

Typography
- Primary: Inter (UI)
- Secondary: Literata (quotes and dreams)

Motion Language
Movement = Life.
- Idle drift (dream nodes)
- Pulse on think (ember core)
- Bloom on long-press (seed growth)
- Prune on swipe (branch retract)

Spatial Metaphor
- Home = Garden
- Dreams = Night Sky
- Memory = Archive
- Pod = Soil

Sound
Ambient, textural, no melody. Low hum, soft crackle.

Gestures
- Tap -> wake or seed
- Long-press -> bloom (expand connections)
- Swipe down -> Dream
- Swipe up -> Memory
- Pod connected -> Soil view

Accessibility
- High contrast by default
- Motion reduced when OS setting is enabled
- Emoji OFF by default; user toggle available
