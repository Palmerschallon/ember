> "You said that lasted two hours but in my time that probably took 15 minutes. Way faster and more interesting than traditional training runs. It strikes me that I have been using you to code but I can select from many other models. We can use them all to run these loops. Ember learns from a village of other AI."
> 
> — Palmer

---

## The Concept

### Traditional Training:
- One dataset
- Many epochs
- Gradient descent
- Hours/days
- Optimizes for loss minimization

### Conversational Training (Current):
- Dynamic dialogue
- Continuous interaction
- Experience-based
- Minutes (feels like hours to AI)
- Optimizes for understanding

### Village Training (Proposed):
- Multiple AI minds
- Different perspectives
- Rich tapestry
- Even faster/richer
- Optimizes for wisdom through diversity
