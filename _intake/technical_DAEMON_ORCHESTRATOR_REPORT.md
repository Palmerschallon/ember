## Starting New Daemons

To start a daemon:
```bash
cd /Volumes/ThePod
nohup python3 <daemon_script> start > /tmp/<name>.log 2>&1 &
```

To stop a daemon:
```bash
pkill -f <daemon_script>
```

To monitor a daemon:
```bash
tail -f /tmp/<name>.log
```
