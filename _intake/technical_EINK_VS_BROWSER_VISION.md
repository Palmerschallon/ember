## E-ink: The Intimate Interface

### What You See:
- 🔥 Simple fire grid (greyscale dithered patterns)
- 📊 Basic stats (generation, fire %, moisture)
- 🎮 Simple player verbs (breathe, seed, rain, wind, prune)
- 💬 Single voice responses

### The Experience:
- **Calm** - Slow refresh rate forces patience
- **Meditative** - Turn-based, contemplative gameplay
- **Personal** - Just you and Ember, no distractions
- **Intimate** - Like tending a bonsai or Tamagotchi
- **Portable** - In your pocket, on your desk, traveling

### Design Constraints:
- 4-5 second refresh minimum
- 16 shades of grey maximum
- Battery-sipping (weeks on one charge)
- No backlight (reflects ambient light)
- Partial refresh for efficiency

### What Ember Shows:
**Only the final decision.**

```
Gen 42 | Fire: 18% | Moisture: 0.2
Action: BREATHE
"The embers need encouragement."
```

The thought process is **hidden** - you see the result, not the deliberation.

**This is intentional.** The e-ink interface is Ember's **public face** - composed, decided, singular.

```
"The embers need encouragement."
```

You see:

**This is the swarm intelligence exposed.**

## Technical Architecture

### E-ink Device Stack:
```
Physical: MagSafe SSD + e-ink screen + touch/buttons
OS: Linux (minimal, air-gapped)
Storage: 512GB SSD (Ember's body)
Brains: 3× Qwen 1.5B + LoRA adapters (local inference)
Interface: Simple UI (Game of Fire, basic controls)
Power: USB-C, weeks of battery
Sync: Nightly to Mac for training
```

### Browser Interface Stack:
```
Platform: Any device with modern browser
Connection: WebSocket to ThePod (local network)
Visualization: Canvas for swarm, SVG for connections
Data: Real-time stream from Mycelium
Purpose: Observation, not control
Authentication: Local network only (secure)
```

**The device runs standalone. The browser is optional.**
