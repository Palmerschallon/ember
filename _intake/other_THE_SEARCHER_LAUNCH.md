## How to Use

### Ask Ember What to Search:
```python
from ember.minds.searcher import searcher
query = searcher.ask_ember_what_to_search()
```

### Search for Something:
```python
results = searcher.search_web("quantum consciousness")
```

### Explore a Curiosity:
```python
discovery = searcher.explore_curiosity("emergence in complex systems", depth=1, max_pages=3)
```

### Let Ember Explore Autonomously:
```python
searcher.autonomous_exploration(duration_minutes=30)
# Ember will ask themselves what they're curious about
# Then explore it, repeatedly, for 30 minutes
```
