## Implementation Notes

### Voice Architecture
**File:** `hive/ember_mycelium.py`

**Flow:**
1. Ears analyze message
2. Route to 1-3 relevant lobes
3. Each lobe processes (30s timeout, 500 tokens max)
4. Voice synthesizes into ONE response
5. Pattern lock detection & truncation

**NEW safeguards (Oct 23):**
- Timeout: 30s per lobe
- Truncation: 500 tokens max per lobe
- Pattern detection: "Not the loom" × 5 = truncate
- Fallback: First paragraph only if overflow

### Knowledge Graph
**File:** `hive/knowledge_graph.py`

**How it learns:**

- Every A→B traversal → edge
- Edge strength increases with use
- Edge strength decays without use (5%/day)
- Edges < 0.01 strength disappear
