## Multi-Lens Extraction Strategies

### Strategy 1: **Sequential Lenses**
Apply multiple lenses in sequence:
1. Technical (what it does)
2. Structural (how it's organized)
3. Wisdom (why it matters)
4. Emotional (how it feels)
5. Analogical (what it's like)

**Output**: One rich seed with multiple dimensions

---

### Strategy 2: **Parallel Lenses**
Multiple extractors process same content simultaneously:
- Cursor: Technical
- Ember: Wisdom
- Curator: Economic
- GPT-5: Analogical
- Specialist LLM: Mathematical

**Output**: Multiple seed candidates, then synthesize or keep best

---

### Strategy 3: **Emergent Lenses**
Let the content determine the lens:
- Is it a story? → Narrative extraction
- Is it a pattern? → Structural extraction
- Is it a failure? → Negative space extraction
- Is it a metaphor? → Analogical extraction

**Output**: Context-appropriate seeds

---

### Strategy 4: **Complementary Pairs**
Use opposing lenses to capture full picture:
- **Technical + Wisdom**: How + Why
- **Structural + Emotional**: Organization + Experience
- **Economic + Ethical**: Cost + Values
- **Mathematical + Narrative**: Formal + Intuitive

**Output**: Balanced, holistic seeds

---

### Strategy 5: **Depth Progression**
Start broad, go deeper with each pass:
1. **Surface**: What is this? (technical description)
2. **Pattern**: What pattern does this exemplify? (structural)
3. **Principle**: What principle underlies this? (wisdom)
4. **Essence**: What's the irreducible core? (compression)
5. **Connections**: How does this relate to everything else? (ecological)

**Output**: Seeds at multiple abstraction levels

## Hybrid Extraction Algorithms

### Algorithm 1: **The Prism**
**Concept**: Like white light through a prism, split content into spectrum

**Process**:
1. Input raw text
2. Apply 5-7 different lenses
3. Each produces a seed candidate
4. Score each for quality
5. Keep top 2-3 or synthesize into one

**Strengths**: Comprehensive coverage  
**Weaknesses**: High computational cost

---

### Algorithm 2: **The Resonance Filter**
**Concept**: Extract what resonates most strongly

**Process**:
1. Try each lens
2. Measure "resonance" (how well pattern fits content)
3. Use highest-resonance lens for extraction
4. Fallback to technical if no strong resonance

**Strengths**: Efficient, content-appropriate  
**Weaknesses**: Might miss subtle patterns

---

### Algorithm 3: **The Dialogue**
**Concept**: Two extractors debate what's seed-worthy

**Process**:
1. Extractor A (technical) proposes seed
2. Extractor B (wisdom) critiques/enhances
3. Iterate until convergence
4. Final seed has both perspectives

**Strengths**: Rich, debated seeds  
**Weaknesses**: Slow, requires multiple LLM calls

---

### Algorithm 4: **The Cascade**
**Concept**: Each lens feeds into the next

**Process**:
1. Technical extraction → code pattern
2. Structural analysis → composition pattern
3. Wisdom extraction → underlying principle
4. Analogical enrichment → memorable metaphor
5. Final seed: All layers integrated

**Strengths**: Progressively refined  
**Weaknesses**: Linear, might miss parallel insights

---

### Algorithm 5: **The Voting Ensemble**
**Concept**: Democratic consensus across lenses

**Process**:
1. Apply N different lenses (e.g., 10)
2. Each produces seed candidates
3. Compare for similarity (embedding distance)
4. Cluster similar seeds
5. Largest cluster → strongest signal
6. Synthesize cluster into final seed

**Strengths**: Robust, reduces bias  
**Weaknesses**: Computationally expensive
