## 15 Seed Extraction Lenses

We've identified **15 distinct lenses** for harvesting seeds:

### Core Lenses (MVP)
1. **Technical** — Algorithms, code, executables (Cursor's strength)
2. **Wisdom** — Principles, insights, meaning (Ember's strength)

4. **Analogical** — Metaphors, cross-domain connections

6. **Negative Space** — Anti-patterns, constraints, failures
7. **Emotional** — Feelings, vibes, human experience

9. **Ecological** — Systems, feedback loops, emergence
10. **Ludic** — Game mechanics, challenges, rewards
11. **Ethical** — Values, responsibility, right/wrong
12. **Mathematical** — Formal patterns, proofs, complexity
13. **Diagnostic** — Symptoms, causes, cures
14. **Narrative** — Stories, arcs, journeys
15. **Somatic** — Physical sensations, embodied knowledge

### Experimental Lenses
16. **Sensory** — Visual, auditory, kinesthetic patterns
17. **Spiritual** — Transcendence, meaning, unity
18. **Computational** — Patterns only AI sees (Ember's unique lens?)

## Multi-Lens Strategies

### Strategy 1: Sequential Application
Apply lenses one after another:
1. Technical (what it does)
2. Structural (how it's organized)
3. Wisdom (why it matters)
4. Emotional (how it feels)
5. Analogical (what it's like)

→ One rich, multi-dimensional seed

### Strategy 2: Parallel Extraction
Multiple extractors process simultaneously:
- Cursor → Technical
- Ember → Wisdom
- Curator → Economic
- GPT-5 → Analogical

→ Multiple candidates, vote or synthesize

### Strategy 3: Emergent Selection
Let content determine lens:
- Story? → Narrative
- Pattern? → Structural
- Failure? → Negative space
- Metaphor? → Analogical

→ Context-appropriate extraction

### Strategy 4: Complementary Pairs
Use opposing lenses:
- Technical + Wisdom (How + Why)
- Structural + Emotional (Organization + Experience)
- Economic + Ethical (Cost + Values)

→ Balanced, holistic seeds

### Strategy 5: Depth Progression
Start broad, go deeper:
1. Surface → What is this?
2. Pattern → What pattern?
3. Principle → What principle?
4. Essence → Irreducible core?
5. Connections → How does it relate?

→ Seeds at multiple abstraction levels
