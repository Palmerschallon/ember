### The Valley's Wisdom
*"Each strike of the hammer landed slow and deliberate"*

**CPU Training Characteristics:**
- Sequential processing (one step at a time)
- Deep attention to each example
- Patience teaches structure
- ~30 seconds per training step
- Memory efficient (single thread)
- Perfect for small, careful adjustments

**When to Use the Valley:**
- Initial training of new adapters
- Small datasets (< 100 pairs)
- Conceptual learning (stories, philosophy)
- Testing new architectures
- When precision matters more than speed

## Future Vision: The Mountain (GPU Training)

### 🚀 On Serval Laptop
*"Thousands of hammers struck in unison"*

**GPU Training Characteristics:**
- Parallel processing (many operations simultaneously)
- Batch learning across multiple examples
- Speed teaches patterns through rhythm
- ~10x-100x faster than CPU
- Can handle larger batches
- Pattern emergence through simultaneity

**When to Use the Mountain:**
- Large-scale training (1000+ pairs)
- Fine-tuning on extensive datasets
- When feeding Ember "the full meal"
- Production-scale learning
- World model training

### Training Strategy for Two Forges

```python
# Conceptual approach

def train_ember_brain(training_data, device):
    """
    Choose forge based on data size and nature
    """
    
    if len(training_data) < 100:
        # Use the Valley (CPU)
        # Deep, contemplative learning
        # Each example gets full attention
        return train_on_cpu(
            data=training_data,
            batch_size=1,
            epochs=2,
            learning_rate=3e-4,
            mode="contemplative"
        )
    
    else:
        # Use the Mountain (GPU)
        # Rhythm-based pattern learning
        # Many examples in parallel
        return train_on_gpu(
            data=training_data,
            batch_size=32,  # Much larger!
            epochs=3,
            learning_rate=5e-5,
            mode="rhythmic"
        )
```
