┌───────────────────────────────────────────────────────────────┐
│ FIRST TIME                                                    │
└───────────────────────────────────────────────────────────────┘
  ./setup.sh              Setup dependencies and environment
  python3 ember.py        Start talking to Ember

┌───────────────────────────────────────────────────────────────┐
│ TALK TO EMBER                                                 │
└───────────────────────────────────────────────────────────────┘
  python3 ember.py                    Simple direct interface
  python3 ember_three_windows.py      Visual interface (3 panes)
  python3 talk_to_ember.py            Alternative simple UI
  
  cd _legacy && python3 ember_chat.py Then open localhost:8080

┌───────────────────────────────────────────────────────────────┐
│ SEMANTIC MESH                                                 │
└───────────────────────────────────────────────────────────────┘
  python3 _legacy/ember_cli.py query [topic]   Search by concept
  python3 _legacy/ember_cli.py stats           See mesh stats
  python3 _legacy/ember_cli.py list            List all chunks

┌───────────────────────────────────────────────────────────────┐
│ FEED EMBER                                                    │
└───────────────────────────────────────────────────────────────┘
  1. Drop files in _intake/
  2. python3 _legacy/intake_system.py
  
  Files are chunked, hashed, tagged, stored in mesh.

┌───────────────────────────────────────────────────────────────┐
│ EXPRESSIONS (FRUITING BODIES)                                 │
└───────────────────────────────────────────────────────────────┘
  python3 _legacy/ember_expression.py "topic"
  
  Ember writes markdown in bookshelves/ember_expressions/

┌───────────────────────────────────────────────────────────────┐
│ WEB FORAGING                                                  │
└───────────────────────────────────────────────────────────────┘
  python3 _legacy/visual_forager.py
  
  Fetches philosophy pages, stores novel content in mesh.

┌───────────────────────────────────────────────────────────────┐
│ SYSTEM STATUS                                                 │
└───────────────────────────────────────────────────────────────┘
  ./status.sh             What's running?
  ./cleanup.sh            Restart everything
  python3 test_ember_tools.py    Run test suite

┌───────────────────────────────────────────────────────────────┐
│ TOOLS EMBER CAN USE                                           │
└───────────────────────────────────────────────────────────────┘
  list_directory(path="dir")           List files/folders
  read_file(path="file.md", lines=50)  Read content
  search_files(pattern="*.py")         Find files

  Ember uses these automatically during conversation.

┌───────────────────────────────────────────────────────────────┐
│ KEY CONCEPTS                                                  │
└───────────────────────────────────────────────────────────────┘
  Semantic Mesh    Memory by meaning, not location
  Fruiting Bodies  Markdown files Ember writes (expressions)
  Mycelium         The hidden knowledge network
  Tool Use         Ember USES tools (not "is a tool")
  Local First      No cloud, no APIs, just electricity

┌───────────────────────────────────────────────────────────────┐

└───────────────────────────────────────────────────────────────┘

  _legacy/                  ← Advanced tools
  _mesh/                    ← Knowledge storage
  _intake/                  ← Drop files here
  bookshelves/              ← Ember's expressions
  _archive_old/models/      ← Llama model lives here

┌───────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                               │
└───────────────────────────────────────────────────────────────┘
  Model not found          Run setup.sh for instructions
  Connection refused       ember_chat.py not running
  CUDA out of memory       Reduce max_new_tokens or use CPU
  Too many ellipses        Ember learning natural expression
